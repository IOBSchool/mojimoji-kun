# 文字起こしもじもじくん

聞いた声を、そっと文字に。

- 🎙 **その場で聞き取る**：マイクで音声を拾って、文字がどんどん出てくる
- 🔗 **リンクから起こす**：FacebookやInstagramのリンクから文字起こし（準備中）
- 📋 コピーボタンですぐ貼り付け
- 💾 Googleスプレッドシートに自動保存

## スプシ保存の設定（最初に1回だけ）

1. 保存用スプレッドシートを開き、「拡張機能」→「Apps Script」
2. `gas/Code.gs` の中身を貼り付けて保存
3. 「プロジェクトの設定」→「スクリプト プロパティ」に `TOKEN` を追加し、好きな合言葉を入れる
4. 「デプロイ」→「新しいデプロイ」→種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」でデプロイ
5. 表示されたURLと合言葉を、もじもじくんの「⚙️保存先の設定」に入れる

## 使うときの注意

- iPhoneはSafari、AndroidはChromeで開く
- 同じスマホで別アプリ（インスタ等）に切り替えると聞き取りが止まるので、音声は別の端末で流す

## リンクから起こす（裏方サーバー）

`server/` がFacebook・Instagramのリンクから音声を取り出すサーバー。Renderの無料プランで動かす。

1. https://dashboard.render.com/blueprints でGitHub連携し、このリポジトリを選ぶ（`render.yaml` を読み込む）
2. デプロイ後、サービスの「Environment」に表示される `TOKEN` が合言葉
3. もじもじくんの「⚙️保存先の設定」に、サーバーURLと合言葉を入れる

無料プランは使わない時に眠るので、最初の1回は起きるまで1分ほどかかる。
